## 예상 질문과 답변

### 1. 왜 LLM만 사용하지 않았나요?

LLM은 근거를 요약하고 질문에 답하는 데 사용합니다. 전압·전류·전력 변화와 정격 비교는 시뮬레이터와 명시된 계산으로 산출해 숫자가 언어 모델의 추측에 의존하지 않게 합니다.

### 2. Bayesian 진단이 필요한 이유는 무엇인가요?

설정된 고장 가설 중 관측값과 일치하는 정도를 조건부로 갱신하고, 아직 측정하지 않은 후보 중 정보량이 큰 위치를 고르는 예시입니다. 현재는 U1 3/6/8 V 저장 시나리오에 한정됩니다.

### 3. 정격 초과가 실제 손상을 뜻하나요?

아닙니다. 계산된 시뮬레이션 스트레스가 입력한 정격값을 넘었다는 뜻입니다. 해당 정격은 시연 가정이며 실제 손상은 별도 검사해야 합니다.

### 4. 왜 ngspice를 사용했나요?

정상 회로와 고장 시나리오의 시간에 따른 노드 및 지원된 소자 응답을 계산하기 위해 사용합니다. 입력 모델이 지원되지 않으면 임의 결과를 만들지 않고 지원되지 않음을 표시합니다.

### 5. 다른 회로에도 적용할 수 있나요?

KiCad XML 연결 분석은 가능하지만 물리 시뮬레이션은 명시적 SPICE 모델과 매핑이 있는 경우에 한합니다. 모든 IC와 모든 회로를 자동 지원하지 않습니다.

### 6. 실제 실험 결과와 비교했나요?

이번 평가 자료에는 독립적인 실물 고장 정답 데이터가 없습니다. 결과는 ngspice 출력과 회로식 기반 참조를 확인했으며, 손상 탐지 정확도나 현장 성능을 주장하지 않습니다.

### 7. 로컬 LLM을 사용한 이유는 무엇인가요?

분석 JSON을 외부 클라우드 API로 보내지 않고 로컬에서 근거 설명을 시도하기 위해서입니다. Ollama가 없거나 응답 검증에 실패하면 결정론적 안내를 사용할 수 있습니다.

### 8. 회로 모델의 한계는 무엇인가요?

고장 모델은 이상화되어 있고, 일부 부품의 전류·전력이나 열·ESR 효과를 계산하지 않습니다. 명시적으로 `UNKNOWN`인 값은 안전 판정으로 해석할 수 없습니다.

### 9. Bayesian Posterior 1.0은 고장 확률 100%인가요?

아닙니다. 현재 세 개의 설정 가설과 가우시안 측정 모델에 조건부인 정규화 결과입니다. 가설 밖의 고장이나 모델 오차를 포함한 현장 고장 확률이 아닙니다.

### 10. RC 결과의 시간 범위는 얼마인가요?

포함된 비교 CSV는 545개 샘플, 0–50 ms입니다. 마지막 샘플의 VC가 정상 약 0.24325 V, RCHARGE 100 kΩ 조건 약 0.02488 V입니다.
