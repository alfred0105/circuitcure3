# Phase 21.2.1 Benchmark Results

## Reproduction record

The checked-in compact records under `data/benchmarks/phase21_2_1/` are generated by `scripts/benchmark_multi_image_component_map.py`. The deterministic geometry fixture uses seed `216` and three 420 × 420 crops with known x offsets 0, 120, and 240 px. The public dataset run uses all 24 TOP/BOTTOM PNG files from PRISM commit `9189c87bbec6995b745b809db99cef6d3269401f`; input SHA-256 values are recorded per board. Runtime and memory numbers are local diagnostics for a single run, not service guarantees.

## Synthetic geometry and identity smoke

The 3-view fixture produced one reference and two registered candidates. Known translation errors were approximately 1.00, 1.00, and 0.97 px. This is a deterministic synthetic smoke test, not an independent landmark score. The estimated mosaic was 660 × 422 px; its valid-pixel coverage was about 99.53%, canvas-footprint ratio 99.08%, and unobserved-area ratio 0.47%. The overlap union occupied about 63.33% of canvas pixels. The injected component identity remained stable when an additional view and the prior map were supplied.

The Phase 21.2 baseline stored the same fixture's canvas size as 660 × 422 px, runtime as 0.125 s, and an estimated scene-rectangle coverage of 100%. Phase 21.2.1 computes the valid-pixel union instead; the result is slightly below 100% because warped pixel masks leave uncovered edge pixels. Current and baseline timings are one-run local readings and may differ with interpreter, allocator, cache, and instrumentation. Python allocation tracing reports only Python allocations and excludes native OpenCV/Pillow memory and process RSS. The selected mosaic source contribution can be zero for one fully overlapped view because the current per-view sharpness heuristic selects pixels from other views.

Synthetic metrics: [`synthetic_summary.json`](../data/benchmarks/phase21_2_1/synthetic_summary.json).

## PRISM local detector pipeline smoke

The existing ignored local model was present and loaded by ONNX Runtime CPU:

- Model ID: `pcb-yolov8s-2026-07-11`
- SHA-256: `45a1dc54bb2eaff067edc631be30fee650deb1236e97a038610faa11aef28424`
- Size: 44,943,271 bytes
- 24 input images across 12 boards; one TOP and one BOTTOM view per board
- The service returned `INFERENCE_COMPLETE` for all views and 39 total candidate observations in this recorded run
- End-to-end run time: recorded in JSON; timing is environment-specific

This validates model loading, invocation, response decoding, and image-to-canonical identity mapping for single-view mosaics. It does not report precision/recall, component recognition accuracy, or same-side photo registration because this dataset supplies only one image per side per sample. PRISM images are public dataset inputs, not a set of independently captured physical-board multiview photos. A local ONNX file is ignored by Git and is not part of the commit.

Detailed input hashes and per-side records: [`prism_pipeline_smoke.json`](../data/benchmarks/phase21_2_1/prism_pipeline_smoke.json). Detector source/checkpoint provenance and the documented upstream license declarations are in [PCB AI detector setup](PCB_AI_DETECTION.md).
