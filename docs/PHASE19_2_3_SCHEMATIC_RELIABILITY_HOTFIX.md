# Phase 19.2.3 — Schematic Reliability Hotfix

## Problem and fix

Reference, UUID, sheet, unit, and geometry agreement alone did not prove that the displayed schematic had the same wiring as the XML netlist used by analysis. The workspace now exports an XML netlist with the installed KiCad CLI and compares it before enabling click-to-inspect mapping. SVG display and the existing connectivity graph remain available when verification is unavailable or reports a mismatch.

## Electrical equivalence

The verifier compares component Reference sets, values, optional Library IDs, connected `(Reference, pin)` partitions, and net identity. A single leading `/` is removed from a net name to normalize KiCad's root-sheet prefix; all remaining hierarchy and name text is preserved. Connectivity is compared as exact pin groups, so net merges, splits, and changed membership fail. A normalized name assigned to multiple pin groups is rejected. Malformed input, duplicate references or pins, missing CLI, export errors, timeouts, and incomplete sheet trees fail closed. Missing Library IDs in supplied XML are reported as `UNKNOWN` metadata and are not invented.

Cache keys include every discovered schematic sheet's relative path and bytes, supplied XML bytes, KiCad CLI version, and verifier version. Only `VERIFIED_EQUIVALENT` and `MISMATCH` outcomes are cached; operational and parsing failures are not. Cache files are local generated data under `data/schematic_equivalence_cache/`.

Per-component pin-number sets are compared when both XML exports provide the `<units>` pin inventory. When the supplied analysis XML omits it, pin-number inventory is explicitly reported as `UNKNOWN`; actual connected pin memberships are still compared exactly.

Click mapping requires all current-context checks: electrical equivalence, verified Reference identity, verified geometry, a matching asset/context key, and a fresh monotonically increasing event sequence. Old page/context events and forged symbol identities are rejected. Inspection selection is separate from the fault component.

## Geometry

For each supported symbol primitive bound corner `(x, y)`, placement angle `θ`, and origin `(cx, cy)`, the page transform is:

```text
rx = x cos θ − y sin θ
ry = −(x sin θ + y cos θ)   # KiCad library Y-up to page Y-down
mirror-x: ry = −ry
mirror-y: rx = −rx
page = (cx + rx, cy + ry)
```

Rotation and both mirror axes were compared against SVG generated by the installed KiCad CLI (10.0.6) using an asymmetric embedded resistor body. Coverage includes 0°, 90°, 180°, 270°, mirror-x/y, and 90° plus each mirror. Unsupported primitives and overlapping hit boxes remain non-interactive. Multi-sheet SVG page-to-instance association is not established; it reports `MULTI_SHEET_MAPPING_PARTIAL` and disables click mapping. Unit and UUID remain part of each verified region identity.

## Browser pointer checks

Manual coordinate-based browser checks were run against the real Divider SVG in the local Streamlit app at `http://127.0.0.1:8503/`:

| Check | Result |
|---|---|
| R1 pointer click | Inspector selected R1 |
| R2 pointer click | Inspector selected R2 |
| J1 pointer click | Inspector selected J1 |
| Fault/inspection separation | Fault remained R1 while R2 and J1 were inspected |
| Empty canvas click | No selection change |
| Zoom then pointer click | R2 selected at approximately 175% zoom |
| Pan then pointer click | R1 selected after dragging the blank canvas |
| Fit-to-view pointer click | Not separately exercised |

These were actual mouse-coordinate clicks; accessibility button activation was not counted as pointer evidence. Browser console and event lifecycle checks are described only to the extent actually run in this report; pointer-cancel, blur, remount, and cross-context forged browser E2E were not automated.

## Viewer lifecycle and limits

The vanilla JavaScript viewer now sends asset identity and a monotonic sequence with selections. Python validates the current context, SVG asset, UUID, Reference, sheet, unit, geometry status, and sequence. Drag state clears on pointer-up/cancel, lost capture, window blur, and page hide. Event listeners and the resize observer are removed on unmount, and the SVG Blob URL is revoked. Pan and zoom remain browser-local and do not trigger analysis events.

Single-sheet mapping is the supported interactive mode. Multi-sheet page mapping remains explicitly partial and fail-closed. Library metadata can remain unknown where the supplied XML omits it. No physical damage probability is inferred. Local runtime/performance profiling was not performed.

## Verification record

The focused electrical and geometry tests, including actual KiCad CLI export integrations, are recorded in the commit verification. Full Python test markers, Ruff, mypy, JavaScript syntax, and cross-version CI outcomes are recorded after execution below.

## Phase decision

The same Divider fixture passed electrical-equivalence checking with KiCad CLI 10.0.6, and real pointer checks confirmed symbol selection and fault/inspection separation through zoom and pan. Phase 19.2.3 is suitable to close after the listed regression and CI checks pass. Phase 19.3 may proceed for single-sheet verified overlays only; multi-sheet overlays must remain disabled until page-to-instance identity is independently verified.
